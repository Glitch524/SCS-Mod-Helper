# SCS Model Maker
### Download
[Latest Version](https://github.com/Glitch524/SCS-Mod-Helper/releases/latest)

### Function：
- App Function
	- Creation and Editing for Manifest file
	- Creation of Mod description file and localization
	- Interior model definition:
		- Interior model sii file for selected vehicles
		- Accessory Hookup model
		- Physics model
		- Search and clean created sii files
	- Model Hookup files for model animation or compass
	- Definition of spray painting: 
		- Definition of paintjob for various vehicle models
		- Browsing paintjob textures
		- Showing the vehicle model's UV map when selecting a vhiecle (currently only supports UV maps for 'Ford: Road Trip' and 'Coaches' models)
	- Localization for item names
	- Support for Converter PIX
		- Supports browsing official SCS files and Mod ZIP files
		- Supports displaying multiple resource pack files in multiple tabs, and you can export the needed resources by mounting multiple resource packs
- About page
	- Support for checking new software versions
- App settings
	- App Localization: English, Simplified Chinese (Follow System by default, English if no corresponding language)
	- Themes: Light, Dark, Follow System

### Probably updates：
- Paint job creation
- List or export files by ConverterPIX

### 包含的功能：
- 软件功能
	- Manifest文件的创建与修改
	- Mod描述文件的创建以及多语言支持
	- 饰品的定义：
		- 各车型的车内模型定义sii文件的生成，支持选择车型生成
		- 套件模型的定义与生成
		- 物理模型的定义与生成
		- 已生成sii文件的查看和清理
	- 模型动画绑定文件的生成
	- 喷漆的定义：
		- 各种车型的喷漆的定义
		- 喷漆贴图的浏览
		- 选择车型时显示对应车型的UV图（目前仅支持《福特：公路之旅》和《客车》的车型UV图）
	- 文字的多语言定义的设置与文件生成
	- Converter PIX的支持
		- 支持浏览官方的SCS文件和Mod的ZIP文件
		- 支持多标签显示多个资源包文件，且可以通过挂载多个资源包导出需要的资源
- 关于页
	- 支持软件新版本检查
- 软件设置
	- 本地化：英语，简体中文（默认跟随系统，没有对应语言则显示英语）
 	- 颜色模式：浅色、深色、跟随系统

### 大概会更新的功能：
- 车辆涂装的定义与生成
- 使用ConverterPIX浏览、导出文件
